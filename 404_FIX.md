# 404 Error Fix - Double Slash Issue

## The Problem

You're seeing this error:
```
POST https://poc-zqkk.onrender.com//auth/login 404 (Not Found)
```

Notice the **double slash** `//auth/login` - this is wrong!

## The Issue

The URL should be:
```
https://poc-zqkk.onrender.com/api/auth/login
```

But it's becoming:
```
https://poc-zqkk.onrender.com//auth/login
```

This happens when:
1. `NEXT_PUBLIC_BACKEND_URL` has a trailing slash: `https://poc-zqkk.onrender.com/api/`
2. The frontend adds `/auth/login`
3. Result: `https://poc-zqkk.onrender.com/api//auth/login` (double slash)

OR

1. `NEXT_PUBLIC_BACKEND_URL` is missing `/api`: `https://poc-zqkk.onrender.com`
2. The frontend code expects `/api` to be in the base URL

## The Fix

### Step 1: Check Vercel Environment Variable

1. Go to **Vercel Dashboard** → Your project → **Settings** → **Environment Variables**
2. Find `NEXT_PUBLIC_BACKEND_URL`
3. Make sure it's set to:
   ```
   https://poc-zqkk.onrender.com/api
   ```
   ⚠️ **Important:**
   - Must include `/api` at the end
   - **NO trailing slash!**
   - Should be: `https://poc-zqkk.onrender.com/api`
   - NOT: `https://poc-zqkk.onrender.com/api/` (trailing slash)
   - NOT: `https://poc-zqkk.onrender.com` (missing /api)

4. If it's wrong, **update it** and click **Save**

### Step 2: Redeploy Frontend

1. Go to **Deployments** tab in Vercel
2. Click **⋯** (three dots) on the latest deployment
3. Click **Redeploy**
4. Wait for deployment to complete (1-3 minutes)

### Step 3: Clear Browser Cache

1. Press `Ctrl + Shift + Delete` (Windows) or `Cmd + Shift + Delete` (Mac)
2. Clear cached images and files
3. Or do a hard refresh: `Ctrl + F5` (Windows) or `Cmd + Shift + R` (Mac)

### Step 4: Test Again

1. Visit: `https://poc-kwpr.vercel.app`
2. Try logging in
3. Check browser console (F12) → Network tab
4. The request should now go to: `https://poc-zqkk.onrender.com/api/auth/login`

## Verify the Correct URL Structure

The frontend code does:
```javascript
const API_BASE_URL = process.env.NEXT_PUBLIC_BACKEND_URL || 'http://localhost:3001/api';
// Then: `${API_BASE_URL}/auth/login`
```

So if `NEXT_PUBLIC_BACKEND_URL = https://poc-zqkk.onrender.com/api`
Then the request becomes: `https://poc-zqkk.onrender.com/api/auth/login` ✅

But if `NEXT_PUBLIC_BACKEND_URL = https://poc-zqkk.onrender.com/api/`
Then the request becomes: `https://poc-zqkk.onrender.com/api//auth/login` ❌ (double slash)
